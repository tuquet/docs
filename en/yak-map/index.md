# 🗺️ Yak Map (`tuquet/yak-map`)

> **Interactive Visual Dependency Graph & Ecosystem Lineage**  
> Map dependencies, data flows, and architectural derivations across 14+ repositories in the Tuquet automation ecosystem.

---

## ⚡ Features

* **Topological Force Canvas**: 2D interactive physics-based dependency layout powered by Vis Network and Nuxt 4.
* **Dual-Tier Filters**: Toggle between core engines (Runner, Browser, Automa, Cloud) and shared packages (`@tuquet/lib`).
* **Guided Ecosystem Tour**: Step-by-step interactive walk through upstream engines, intermediate orchestrators, and edge workers.
