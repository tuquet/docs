# 📚 Tuquet Library (`tuquet/lib`)

> **Enterprise Vue 3 Component System, High-Density Data Tables & Automation Primitives**  
> Battle-tested UI primitives built on Shadcn-Vue, Radix Vue, and TanStack Table.

---

## 📦 Packages in Monorepo

| Package | Directory | Description |
| :--- | :--- | :--- |
| **`@tuquet/vue-ui`** | `packages/vue-ui` | Production-ready Vue 3 components styled with Tailwind CSS / UnoCSS with full dark mode support. |
| **`@tuquet/vue-table`** | `packages/vue-table` | Virtualized, remote-driven high-density data table with column pinning, sorting, and filtering. |
| **`@tuquet/md-export`** | `packages/md-export` | Markdown folder compiler exporting into publication-grade vector PDFs, HTML, PNG, and JPEG. |
| **`@tuquet/extension-runner`**| `packages/extension-runner`| Headless test harness to execute Chrome extensions inside automated CI/CD runners. |
| **`@tuquet/lunar`** | `packages/lunar` | Astronomical Vietnamese Lunar-Solar calendar recurrence engine and Can Chi calculation library. |
