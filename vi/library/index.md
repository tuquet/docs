# 📚 Thư Viện Giao Diện Tuquet (`tuquet/lib`)

> **Hệ Thống Thành Phần Giao Diện Vue 3, Bảng Dữ Liệu Lớn & Tiện Ích Trình Duyệt**  
> Xây dựng trên nền tảng Shadcn-Vue, Radix Vue và TanStack Table với hiệu năng render mượt mà.

---

## 📦 Các Gói Thành Phần (Packages)

* **`@tuquet/vue-ui`**: Bộ component hiện đại, sẵn sàng giao diện Dark/Light mode và thiết kế accessible (WCAG).
* **`@tuquet/vue-table`**: Bảng hiển thị dữ liệu mật độ cao, hỗ trợ phân trang từ xa, ghim cột, lọc và tìm kiếm không lag giật.
* **`@tuquet/md-export`**: Công cụ biên dịch thư mục Markdown xuất ra file PDF vector, HTML và ảnh chất lượng cao.
* **`@tuquet/extension-runner`**: Môi trường giả lập chạy headless extension Chrome trong môi trường CI/CD tự động.
* **`@tuquet/lunar`**: Thuật toán thiên văn chuyển đổi lịch Âm - Dương, chu kỳ Can Chi và ngày lễ truyền thống.
